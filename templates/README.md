
In this directory you can add custom Jinja2 templates for Quarto course generator. These templates are used to generate the course website, slides, handouts, and assignments. 

+ The [default templates](https://github.com/xylomorph/quarto-coursegen/tree/main/src/quarto_coursegen/package_data/templates) can be found in the `quarto-coursegen` package.
+ For more information, see the [Quarto course generator documentation](https://sebastiancacean.de/quarto-coursegen/templates.html).
